# BI 告警诊断

仅处理已归属 App 或 App—设备联动范围的 BI 告警，不负责 VOC 聚类、正式需求评审或上线复盘。

先区分原始观测、指标定义、告警规则和推断。核对指标名称、计算口径、产品线、版本、时间窗、阈值、实际值及数据质量。任何缺失项都列为待补，不得虚构数值、趋势或关联版本；无法核对口径或数值时，不得宣称告警有效或已找到根因。

可核对时说明偏离程度、受影响的用户任务及范围，再列可能原因和验证办法。候选需求只描述需要解决的问题与证据，不把“告警”自动等同于功能需求。输出每条观察和候选的原文引用、待验证假设、证据缺口和下一步；如证据不足，允许零候选。
